# PDF Preview Print

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

在儲存之前，先以 PDF 頁面的形式預覽筆記，並可直接列印。可選擇紙張、邊界、文字大小、彩色或黑白，並保留筆記中的每個空行。

## 功能

- **預覽**：視窗中顯示與 PDF 完全相同的頁面。每次變更選項，預覽都會更新。
- **儲存為 PDF**：每次選擇儲存位置，或儲存到儲存庫中筆記所在的資料夾。
- **列印**：使用系統的列印對話框列印。
- **選項**：紙張大小（A3、A4、A5、B4、B5、Letter、Legal）、直向或橫向、邊界、文字大小、以筆記名稱作為標題、頁碼、行號（預設關閉）。
- **彩色或黑白**：黑白會把色彩、醒目標示和圖片變為灰色。列印時也會將印表機設為灰階。
- **保留空行**：Markdown 通常把連續的多個空行顯示為一個間隔。開啟此選項後，每個空行都會像編輯器中一樣在頁面上留白。可在匯出視窗和設定中切換（預設開啟）。可選擇是否也包括清單和數學公式區塊（預設都包括）；數學公式區塊會在空行處拆分為多個公式。程式碼區塊中的空行一律保留。
- **閱讀檢視中的空行**：閱讀檢視也會把每個空行（包括清單項目之間的）顯示為空白（可在設定中關閉）。
- 設定、指令和訊息支援英語、日語、簡體中文、繁體中文、韓語、西班牙語、法語和德語。首次使用時跟隨 Obsidian 的語言，可在設定中變更。

## 使用方式

- 命令面板：**將目前筆記預覽、儲存或列印為 PDF**。
- 或在筆記的 **…** 選單中，或在檔案清單中右鍵點選筆記：**PDF 預覽與列印**。
- 在右側變更選項，然後按 **儲存 PDF** 或 **列印**。**設為預設** 會保留這些選項供下次使用。

## 注意事項

- 僅限桌面版（Windows、macOS、Linux）。
- PDF 使用 Obsidian 的淺色主題、你的 CSS 片段以及其他外掛的樣式產生。
- 如果頁碼沒有顯示，請下載最新的安裝程式更新 Obsidian。
- 行號依列印出的文字行編號，貫穿整篇筆記。
- 設定頁面中也寫有開啟預覽的方式。

## 檔案與網路

- 外掛會讀取你匯出的筆記。PDF 只儲存到你選擇的位置，或在設定後儲存到筆記所在的資料夾；該處同名的 PDF 會被取代。
- 使用 Obsidian 桌面版的基礎 Electron 來產生 PDF、列印和顯示儲存對話框。
- 儲存位置設為「每次選擇」時，PDF 透過 Node.js 的檔案模組（fs）只寫入你在儲存對話框中選擇的檔案。不會讀寫電腦上的其他檔案。如果希望全部在儲存庫內完成，請把儲存位置設為「筆記所在資料夾」。
- 不使用網路。外掛可離線運作，不收集任何資料。
