# PDF Preview Print

[English](../README.md) | [日本語](README.ja.md) | **简体中文** | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

在保存之前，先以 PDF 页面的形式预览笔记，并可直接打印。可选择纸张、页边距、文字大小、彩色或黑白，并保留笔记中的每个空行。

## 功能

- **预览**：窗口中显示与 PDF 完全相同的页面。每次更改选项，预览都会更新。
- **保存为 PDF**：每次选择保存位置，或保存到库中笔记所在的文件夹。
- **打印**：使用系统的打印对话框打印。
- **选项**：纸张大小（A3、A4、A5、B4、B5、Letter、Legal）、纵向或横向、页边距、文字大小、以笔记名称作为标题、页码、行号（默认关闭）。
- **彩色或黑白**：黑白会把颜色、高亮和图片变为灰色。打印时也会将打印机设为灰度。
- **保留空行**：Markdown 通常把连续的多个空行显示为一个间隔。开启此选项后，每个空行都会像编辑器中一样在页面上留出空白。可在导出窗口和设置中开关（默认开启）。可选择是否也包括列表和数学公式块（默认都包括）；数学公式块会在空行处拆分为多个公式。代码块中的空行始终保留。
- **阅读视图**：在阅读视图中显示空行和缩进的功能，现在是独立插件 [Editor-like Reading View](https://github.com/H9-G/editor-like-reading-view)，也可在移动端使用。
- **保留缩进**：用空格或制表符缩进的行，在 PDF 中也像编辑器中一样保持缩进，而不会变成代码。列表不受影响。可在设置和导出窗口中关闭。
- 设置、命令和消息支持英语、日语、简体中文、繁体中文、韩语、西班牙语、法语和德语。首次使用时跟随 Obsidian 的语言，可在设置中更改。

## 使用方法

- 命令面板：**将当前笔记预览、保存或打印为 PDF**。
- 或在笔记的 **…** 菜单中，或在文件列表中右键点击笔记：**PDF 预览与打印**。
- 在右侧更改选项，然后点击 **保存 PDF** 或 **打印**。**设为默认** 会保留这些选项供下次使用。

## 须知

- 仅限桌面版（Windows、macOS、Linux）。
- PDF 使用 Obsidian 的浅色主题、你的 CSS 片段以及其他插件的样式生成。
- 如果页码没有显示，请下载最新的安装程序更新 Obsidian。
- 行号按打印出的文字行编号，贯穿整篇笔记。
- 设置页面中也写有打开预览的方法。

## 文件与网络

- 插件会读取你导出的笔记。PDF 只保存到你选择的位置，或在设置后保存到笔记所在的文件夹；该处同名的 PDF 会被替换。
- 使用 Obsidian 桌面版的基础 Electron 来生成 PDF、打印和显示保存对话框。
- 保存位置设为“每次选择”时，PDF 通过 Node.js 的文件模块（fs）只写入你在保存对话框中选择的文件。不会读写电脑上的其他文件。如果希望全部在库内完成，请把保存位置设为“笔记所在文件夹”。
- 不使用网络。插件可离线运行，不收集任何数据。
