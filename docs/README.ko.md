# PDF Preview Print

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

노트를 저장하기 전에 PDF 페이지로 미리 보고, 바로 인쇄할 수 있습니다. 용지, 여백, 글자 크기, 컬러 또는 흑백을 고를 수 있고, 노트의 빈 줄도 그대로 유지할 수 있습니다.

## 기능

- **미리 보기**: PDF와 똑같은 페이지를 창에서 확인할 수 있습니다. 옵션을 바꿀 때마다 미리 보기가 바뀝니다.
- **PDF로 저장**: 매번 저장 위치를 고르거나, 보관함 안의 노트와 같은 폴더에 저장합니다.
- **인쇄**: 시스템 인쇄 창으로 인쇄합니다.
- **옵션**: 용지 크기(A3, A4, A5, B4, B5, Letter, Legal), 세로 또는 가로, 여백, 글자 크기, 노트 이름을 제목으로, 쪽 번호, 줄 번호(기본값은 꺼짐).
- **컬러 또는 흑백**: 흑백으로 하면 색, 하이라이트, 그림이 회색이 됩니다. 인쇄할 때도 프린터를 회색으로 설정합니다.
- **빈 줄 유지**: Markdown은 보통 연속된 빈 줄을 하나의 간격으로 보여 줍니다. 이 옵션을 켜면 편집기처럼 빈 줄마다 페이지에 여백이 생깁니다. 내보내기 창과 설정에서 켜고 끌 수 있습니다(기본값은 켜짐). 목록과 수식 블록 안에도 적용할지 고를 수 있습니다(둘 다 기본값은 켜짐). 수식 블록은 빈 줄에서 별도의 수식으로 나뉩니다. 코드 블록의 빈 줄은 항상 그대로 나옵니다.
- **읽기 보기**: 읽기 보기에서 빈 줄과 들여쓰기를 표시하는 기능은 모바일에서도 작동하는 별도 플러그인 [Editor-like Reading View](https://github.com/H9-G/editor-like-reading-view)로 옮겨졌습니다.
- **들여쓰기 유지**: 스페이스나 탭으로 들여 쓴 줄은 PDF에서도 코드가 되지 않고 편집기처럼 들여 써집니다. 목록은 바꾸지 않습니다. 설정과 내보내기 창에서 끌 수 있습니다.
- 설정, 명령, 메시지는 영어, 일본어, 중국어 간체, 중국어 번체, 한국어, 스페인어, 프랑스어, 독일어로 볼 수 있습니다. 처음에는 Obsidian의 언어를 따르며, 설정에서 바꿀 수 있습니다.

## 사용 방법

- 명령 팔레트: **현재 노트를 PDF로 미리 보기·저장·인쇄**
- 또는 노트의 **…** 메뉴나 파일 목록에서 노트를 오른쪽 클릭: **PDF 미리 보기 및 인쇄**
- 오른쪽에서 옵션을 바꾼 뒤 **PDF 저장** 또는 **인쇄**를 누릅니다. **기본값으로 저장**을 누르면 다음에도 같은 옵션으로 열립니다.

## 알아 두기

- 데스크톱 전용입니다(Windows, macOS, Linux).
- PDF는 Obsidian의 밝은 테마, CSS 스니펫, 다른 플러그인의 스타일로 만들어집니다.
- 쪽 번호가 나오지 않으면 최신 설치 프로그램으로 Obsidian을 업데이트하세요.
- 줄 번호는 인쇄되는 텍스트 줄마다 노트 전체에 걸쳐 이어서 붙습니다.
- 설정 화면에도 미리 보기를 여는 방법이 나와 있습니다.

## 파일과 네트워크

- 내보내는 노트를 읽습니다. PDF는 고른 위치에만, 또는 그렇게 설정한 경우 노트와 같은 폴더에만 저장하며, 그곳에 같은 이름의 PDF가 있으면 대체합니다.
- PDF 생성, 인쇄, 저장 창 표시에 Obsidian 데스크톱 앱의 기반인 Electron을 사용합니다.
- 저장 위치를 “매번 선택”으로 하면 PDF는 Node.js의 파일 모듈(fs)로 저장 창에서 고른 파일에만 기록됩니다. 컴퓨터의 다른 파일은 읽거나 쓰지 않습니다. 모두 보관함 안에서 처리하려면 저장 위치를 “노트와 같은 폴더”로 설정하세요.
- 네트워크를 사용하지 않습니다. 오프라인으로 작동하며 데이터를 수집하지 않습니다.
