# PDF Preview Print

[English](../README.md) | **日本語** | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

ノートをPDFのページとしてプレビューしてから保存・印刷できます。用紙・余白・文字の大きさ、カラーか白黒かを選べて、ノートの空白行もそのまま反映できます。

## できること

- **プレビュー**: PDFと同じページの見た目を画面で確認できます。設定を変えると、すぐにプレビューに反映されます。
- **PDFで保存**: 保存先は毎回選ぶか、Vault内のノートと同じフォルダにできます。
- **印刷**: システムの印刷画面から印刷します。
- **設定**: 用紙サイズ（A3、A4、A5、B4、B5、Letter、Legal）、縦・横、余白、文字の大きさ、ノート名をタイトルにする、ページ番号、行番号（初期値はオフ）。
- **カラー・白黒**: 白黒にすると、色・ハイライト・画像がグレーになります。印刷するときも、プリンターをグレーに設定します。
- **空白行を反映**: Markdownでは、続けて入れた空白行は1つ分にまとめられます。この設定では、エディタと同じように空白行の数だけページに空白を入れます。エクスポート画面と設定画面の両方で切り替えられます（初期値はオン）。リストと数式ブロックの中も反映するかを選べます（どちらも初期値はオン）。数式ブロックは空白行のところで別々の数式に分けます。コードブロックの空白行はいつもそのまま出ます。
- **リーディングビュー**: リーディングビューで空白行とインデントを反映する機能は、スマホでも使える別のプラグイン [Editor-like Reading View](https://github.com/H9-G/editor-like-reading-view) に移りました。
- **インデントを反映**: スペースやタブで字下げした行を、PDFでもエディタと同じように字下げします（コードにはなりません）。リストは変えません。設定とエクスポート画面でオフにできます。
- 設定、コマンド、メッセージは、英語、日本語、簡体字中国語、繁体字中国語、韓国語、スペイン語、フランス語、ドイツ語で表示できます。最初はObsidianの言語に合わせ、設定で変更できます。

## 使い方

- コマンドパレット: **今のノートをPDFでプレビュー・保存・印刷**
- またはノートの **…** メニューか、ファイル一覧でノートを右クリック: **PDFのプレビュー・印刷**
- 右側で設定を変えて、**PDFを保存** か **印刷** を押します。**この設定を既定にする** で、次回も同じ設定で開けます。

## 注意

- デスクトップ版（Windows、macOS、Linux）専用です。
- PDFは、Obsidianのライトテーマ、CSSスニペット、ほかのプラグインのスタイルで作られます。
- ページ番号が出ない場合は、最新のインストーラーでObsidianを更新してください。
- 行番号は、印刷される文字の行ごとに、ノート全体で通し番号を付けます。
- 設定画面にも、プレビューの開き方を載せています。

## ファイルとネットワーク

- エクスポートするノートを読み取ります。PDFは、選んだ場所か、設定した場合はノートと同じフォルダにだけ保存します。同じフォルダに同じ名前のPDFがあると置き換えます。
- PDFの作成、印刷、保存画面の表示に、Obsidianデスクトップ版の土台であるElectronを使います。
- 保存先を「毎回選ぶ」にした場合、PDFはNode.jsのファイル機能（fs）で、保存画面で選んだファイルにだけ書き込みます。パソコンのほかのファイルは読み書きしません。すべてVault内で済ませたい場合は、保存先を「ノートと同じフォルダ」にしてください。
- ネットワークは使いません。オフラインで動き、データも集めません。
